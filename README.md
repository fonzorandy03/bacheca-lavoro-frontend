# Bacheca Lavoro – Front-end (Flutter)

    flutter pub get
    flutter run

Indirizzo del server: di default `http://10.0.2.2:8090` (emulatore Android).
Su telefono reale, con PC e telefono sulla stessa Wi-Fi, tocca l'icona server in alto
nella bacheca e inserisci `http://<IP-del-PC>:8090` (vedi `ipconfig`).
